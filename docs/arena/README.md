# 自作AI vs やねうら王 — 2026-09-21

Shogi Search Lab v0.4（提供された最新版）と、既存サイト同梱のやねうら王 NNUE KP256 6.03 / WASM 0.1.2 を実際に対局させた。自作の探索・評価コードは変更していない。先後を入れ替えて2局を行った。

| 対局 | 自作AIの手番 | 結果 | 手数 |
|---|---|---|---:|
| 第1局 | 先手 | やねうら王の勝ち・詰み | 76 |
| 第2局 | 後手 | やねうら王の勝ち・詰み | 79 |

## 実行条件

- 平手の初期局面。双方1スレッド、1手3,000ms、定跡なし、相手番の先読みなし。
- 自作AI：`go depth 8 time 3000 nodes 1000000000`。既定の50,000保持ノード、上位5候補、root-policy screen。1手ごとに `advance` で実際の棋譜と利用可能な部分木を引き継ぐ。相手番には分析しない。
- 深さ・ノード上限より時間予算を優先して使えるよう、ノード上限のみ10億に設定。実際の自作AIの全77回の着手探索は時間上限で終了。
- やねうら王：`go movetime 3000`、MultiPV 1、USI_Hash 32MiB。NNUEは2019-01-15 KP256。同梱版の実行確認であり、現代の大会版の性能比較ではない。
- 入玉宣言は双方無効。詰み、合法手なし、投了、千日手、連続王手で終局。256手で打ち切るが、今回は2局とも詰みで終局。
- 厳密な切れ負けは適用せず、指令から応答までの実測時間を記録。通常は約3秒、やねうら王が終盤で詰みを確定したときは数ms〜数十msで着手。

| 測定 | 第1局 自作AI | 第1局 やねうら王 | 第2局 自作AI | 第2局 やねうら王 |
|---|---:|---:|---:|---:|
| 思考時間の中央値 | 3,001.56ms | 3,003.96ms | 3,001.54ms | 3,003.60ms |
| 出力された深さの中央値 | 5 | 17 | 5 | 18.5 |

深さの定義は同一ではない。自作AIは固定深さの上位5候補比較、やねうら王は選択的探索である。C++ネイティブとWASMの違い、NNUEと駒得評価の違いもあり、深さや速度の数値を直接のアルゴリズム優劣としない。

## 観察

第1局は、自作AIが端歩・角・桂などを動かす間に後手の端攻めが進み、終盤は玉周辺の駒を取られて詰んだ。第2局でも自作AIは序中盤に自分の駒得評価を0付近と見る局面が続く一方、相手の攻めを止められなかった。これは今回の棋譜上の観察であり、個別の枝刈りや評価項目の因果検証ではない。

今回の試験で勝率・段級位は推定しない。自作AIがどこで読みを外すかを今後調べるため、着手直前の上位5候補、完了深さ、評価、読み筋、境界再利用数、探索ノード数、実際の着手による木の引継ぎを残した。新しい強化は今回の対局後も加えていない。

## 観戦画面

`dist/arena.html` を通常のサイトと同じ方法で配信する。実対局の記録を再生する画面であり、ブラウザで新規対局を計算するものではない。デフォルトの再生間隔は3秒。実測時間での再生、一時停止、前後移動、対局切替、盤面反転、読み筋の盤面表示、KIF出力に対応。

評価値は着手前の手番側から見た、各エンジン固有の尺度として表示。異なるエンジンの値を1本の形勢グラフにしない。読みの局面と実対局の局面は画面上で区別する。

## 再現・検証

```bash
make -C engines/shogi-search-lab -j2
node scripts/arena-match.mjs
node scripts/verify-arena.mjs
```

時間制限を使うため再実行時の棋譜は完全一致するとは限らない。実行前後のエンジン初期化は計測外。今回の対局は既にビルド済みの同一ソースのネイティブ実行ファイルを `SHOGI_LAB_BIN` で指定した。元ソースZIP、実行ファイル、WASM、NNUE、各自作ソースファイルのSHA-256は `dist/arena-data.json` に記録。

`protocol.jsonl` に実際の入力・応答を時刻付きで保存。公開画面の全155着手・全候補の読み筋は、対局中にもtsshogiで合法性検査し、C++内部の盤面と照合した。`verification.json` は保存棋譜の再読込、全局面、全PV、終局の詰み、KIF再読込一致を検証した結果。

既存C++のselftestは115件、session-selftestは1,274件通過。観戦UIでは再生・一時停止・先後切替・巻き戻し・最終局面・盤面反転・読み筋表示を確認し、390px幅でも盤と再生操作が表示されることを確認した。

自作コードおよびやねうら王のライセンス・出所は `engines/shogi-search-lab/THIRD_PARTY.md`、サイトの `THIRD_PARTY.md` と同梱のライセンス文書を参照。
