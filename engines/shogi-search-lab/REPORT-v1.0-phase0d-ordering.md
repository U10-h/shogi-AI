# v1.0 Phase 0d — 駒取り・成り優先の読み順

2026-09-27開始。Phase 0cと同じ2局面・主探索深さ2・静止探索予算2のまま、読み順だけを変更した。比較14探索と中断・復元確認10探索を完了した。角交換後の局面では評価値・最善手・PVを保って1,691→926ノード（45.24%減）。初期局面は195→195ノードで変化しなかった。これは既知の浅い2局面での探索効率の結果であり、棋力改善や未知局面での一般化は未検証。

## 実装と固定条件

`native/phase0d_search.cpp` を別バイナリに接続した。`Phase0MoveOrder=lexical|tactical` を追加し、既定はlexical。tacticalでは「駒取りまたは成り」を先、それ以外を後に配置する。同じ区分ではUSI文字列順を保つ。取る駒の価値やSEEによる順位付けはまだ使わない。

主探索・静止探索に同じ順序規則を適用する。非王手の静止探索ではもともと駒取り・成りだけが候補なので、この2区分の並べ替えによる順序変更は起きない。静止探索で変わるのは、静かな回避手も含む王手時の並びである。

盤面・合法手生成・NNUE・葉の条件・探索窓・反復深化はPhase 0cと共通。新たな枝の削除や深さ削減はない。TT、LMR、学習は追加していない。固定上流YaneuraOu 6.03/KP256、Threads=1、Hash=16 MiB、MultiPV=1、定跡なし、全合法手、`go depth 2 nodes 400000 movetime 3000`。通常の静止探索予算2、非終端の絶対ply8で中断する規則も維持した。

入力は `experiments/phase0b-positions.json` の2局面。探索は直列実行し、1コマンドにつき1局面で保存する。1探索の外部応答待ちは8秒。

## 結果

以下のノード数は反復深化の深さ1と2の合計で、上流のdo_moveカウンタを使用する。全幅は限定静止探索の規則で定まる木を省略せず読む参照実装を指す。

| 局面 | 全幅・辞書順 | 全幅・駒取り成り優先 | αβ・辞書順 | αβ・駒取り成り優先 | αβの削減率 | 最善手 / raw評価 |
|---|---:|---:|---:|---:|---:|---|
| 初期局面 | 1,364 | 1,364 | 195 | 195 | 0.00% | `2g2f` / 92 |
| 角交換後 | 72,437 | 72,437 | 1,691 | 926 | 45.24% | `3i4h` / 29 |

4設定すべてで各局面の評価値・最善手・PVが一致。全幅の訪問数、静止探索ノード数、評価呼出数、最大到達plyも読み順の変更前後で一致した。両局面とも主探索深さ2を完了し、最大到達plyは初期局面4、角交換後5だった。

角交換後のαβでは、主探索の順序変更が16回、静止探索で33回発生した。主探索のcutoff総数は74回で同じだったが、最初の候補でのcutoffは21→30回となった。静止探索の訪問数は1,614→849に減った。読み順変更により境界が早く得られ、後続の探索量が減ったことと整合する。

ただし、主探索と王手回避の順序を同時に変更しているため、765ノードの削減をそれぞれの効果へ分解したものではない。また、`main_skipped_siblings` / `q_skipped_siblings` はcutoff時に残った直下の兄弟手数の合計であり、その配下を含む節約ノード数や因果帰属量ではない。cutoff数の減少だけを効果減少とは解釈しない。

初期局面のαβでは実際に順序が変わったリストが0件だったため、ノード数も変わらなかった。全幅側では王手回避の並べ替えが5回あったが、すべて探索するため訪問数は不変。

時間の単回観測は初期局面1.864→1.969 ms、角交換後16.132→12.693 ms。NNUE全再計算の監査を含み、反復測定もしていないため、速度改善率の根拠にはしない。深さ2の標準YaneuraOuはそれぞれ63、185ノードだったが、探索・静止探索・選択性が異なるので同一木の比較ではない。

## 検証

| 確認 | 結果 |
|---|---|
| Phase 0c標準探索と新バイナリ標準探索 | 両局面で評価・最善手・PV・ノード・完了深さが一致 |
| Phase 0cαβと新バイナリ辞書順αβ | 両局面で評価・最善手・PV・ノード・完了深さが一致 |
| 辞書順／優先順 × 全幅／αβ | 両局面で評価・最善手・PVが一致 |
| NNUE差分評価と全再計算 | 新バイナリの上記8探索で149,298照合、不一致0 |
| PV合法性 | 比較・中断確認の全探索で確認 |
| 2ノードでの静止探索中断 | 両局面で上限・中断・根の復元を確認 |
| 外部stopによる中断 | 両局面で中断・根の復元を確認 |
| 中断後、position再設定なしで再探索 | 両中断方式・両局面で基準の評価・手・PV・ノードに一致 |
| NNUE監査無効 | 両局面で同じ評価・手・PV・ノード |

読み順で同点の最善手が変わる場合に備え、各選択手を根で固定した全幅探索で同点を確かめる処理も用意した。今回は手が一致したため、その追加経路は発動しておらず未検証。絶対ply8の中断経路も未発動。

## 判断と次の小規模実験

駒取り・成り優先を、次の検証に進める候補とする。今回の既知2局面で正しい評価を保つことと、うち1局面でのノード削減を確認した。学習による成果ではなく、既存の基本的な手順序付けの接続・計測結果である。v0.x全体の移植、対局、深い教師による着手品質評価は未実施。

次は探索深さや予算を増やさず、事前に固定した中盤局面をまず1つ追加する。同じ4設定の評価一致とノード数を測り、40万ノード・3秒・ply8に達したら未完了として保存する。全幅が完了しない場合、同じ木での一致を確認したとは扱わない。置換表や学習は同時に追加しない。
