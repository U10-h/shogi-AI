# 学習型α更新リスク・探索コストモデル

用途：固定された将棋探索の静止探索で、取りを省略する実験。既定の枝刈りは `off` のまま。棋力向上・未知局面での安全性は保証しない。

## モデルと対応条件

- `alpha-risk.txt`：17入力のロジスティック回帰。完了した基準子探索が親のαを更新したかを予測する。ファイル内閾値は0.05。
- `alpha-risk-cost.txt`：同じリスク係数に、基準子探索が4ノード以上かを予測する17係数を追加。ファイル内リスク閾値0.01、コスト確率閾値0.02。
- 対局候補 `efficient0025` は実験スクリプトの別名。CLIでは `--prune-policy efficient --prune-model models/v0.13/alpha-risk-cost.txt --prune-probability 0.0025` とする。
- PVS、qdepth=6、元NNUE、追加の選択的探索なしで収集・評価した。C++は形式・有限係数・範囲・探索方式を検査するが、評価ファイルのハッシュとの一致は実験ハーネスが検査する。他の評価関数へ無校正で転用しない。
- 評価ファイルSHA-256：`cf7645f64bf6baa5c74612799ce562752f7985923b1f0fc2e6092c998ed867f9`。
- リスクモデルSHA-256：`dda2dda8455e9736bcfe82a121f3a446604b5f891304fbc51deb2487bc29f081`。
- コスト追加モデルSHA-256：`a7ce843beff45425006a5f92be7b3409bce545ee01eaa50f10a29671ef1130f9`。

## データ・学習

v0.10の既存進行のうち、学習game 0–63、校正128–143、開発144–159を使用。非王手・16手目以降・教師評価絶対値2000cp以下の候補から32手目・64手目に近い根を選び、根の一致・左右反転一致を除外した。学習の1進行は採用可能な根がなく、実使用は63対局126根。校正と開発は各16対局32根。1根24,000ノードの反復深化を収集した。

学習859,143ラベル、校正220,581ラベル、開発221,594ラベル。全体で1,301,318ラベル、途中停止した子95件を除外。訪問回数で重み付けされた観測で、1ラベルが1つの独立局面・独立試行ではない。各分割の記録された親局面の一致・左右反転一致の重複は0。最終評価は別seedの新規24進行で行った。

L2正則化0.0001（定数項は除外）、クラス重み付けなしの凸ロジスティック損失を、減衰付きNewton法で最適化する。NNUEは更新しない。ログのfail-soft値そのものは回帰しない。校正のBrier scoreは0.052764、学習平均を常に返す対照は0.179912。ただし、この平均精度だけで実際の省略の安全性は決まらない。

## 特徴（順序がファイル形式）

| index | 意味 |
|---:|---|
| 0 | 定数1 |
| 1 | `(alpha - stand) / 900`、−8〜8に制限 |
| 2 | `(alpha - stand - gainRaw) / 900`、−8〜8に制限 |
| 3 | 持駒増加を含む取りの価値 `gainRaw / 1800` |
| 4 | 取り手の駒価値 raw / 900 |
| 5 | 静止探索残り深さ / 6 |
| 6 | 0始まり手順順位、16で制限して / 16 |
| 7 | 並べ替え後の候補数、16で制限して / 16 |
| 8 | 直前の手と同じ着手先か |
| 9 | 着手先が敵玉からChebyshev距離2以内か |
| 10 | 敵持駒価値 raw / 3600、上限4 |
| 11 | 自持駒価値 raw / 3600、上限4 |
| 12 | `abs(stand) / 3600`、上限4 |
| 13 | index 2の未制限値を0〜8に制限 |
| 14 | 取る駒が角・飛車（成りを含む）か |
| 15 | 取り手が玉か |
| 16 | 取る駒が成っていない歩か |

駒価値は既存のpawn100値×0.9でraw pawn90へ変換する。モデル内の予測値はC++ではlogitの内積と比較し、実行時の指数計算を省く。

## 限界

新規監査16根では、保守的な0.25%版にも182省略中1件のα更新見落としがあった。予測リスク0.152%の飛車による歩取りが、基準探索ではαを139raw超えた例を `results/v0.13/counterexamples.json` に保存した。深さにより反撃の評価が往復し、浅い確認にも限界がある。

このモデルは現在局面の少数特徴しか見ておらず、着手後のNNUE変化や遠い利き、取り返し手順を直接表現していない。探索コストもノード分類にすぎない。総合的な速度・着手品質・対局結果は `REPORT-v0.13.md` を参照。
