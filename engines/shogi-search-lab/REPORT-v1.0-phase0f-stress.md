# v1.0 Phase 0f — 中盤・終盤ストレス試験と読み順の切り分け

2026-09-28。中盤2局面・終盤2局面で「主探索のみ／静止探索の王手回避のみ／両方」の並べ替えを比較し、さらに過去に初回反復が未完了だった終盤を1局面追加した。各探索は主探索深さ2、通常の静止探索予算2、40万ノード・3秒のまま。1局面ずつ直列で進め、計49探索を保存した。

**両方の並べ替えは5局面中4局面でノードを削減したが、追加中盤では55.3%増加した。主探索の駒取り優先を一律に採用する判断は見送る。** 5局面×4設定のαβはすべて深さ2を完了し、各局面内で評価・最善手・PVが一致した。全候補の全幅照合が深さ2まで完了したのは、追加した過去失敗局面の1件だけである。

## 1. 局面の選び方と難しさの範囲

最初の4局面は、既存Phase 0aの中盤・終盤4件を元の順序のまま、今回の結果を見る前に固定した。元のv0.7棋譜のSFENと照合している。最初の中盤はPhase 0eからの再現用である。

その4件の終了後、難しい既知の反例として、v0.16で初回反復が1秒以内に終わらなかった6局面のうち最も早い77手目を追加すると決めた。この局面の再測定結果を見て選び直していない。元の76手の履歴を合法手実装で再生して盤面を確認し、入力に履歴・元ファイルのハッシュを保存した。探索自体は他の4件と揃えて単独SFENから開始した。

## 2. 比較方法

同じ固定YaneuraOu 6.03/KP256の盤面・合法手・NNUE・do_moveカウンタを利用する。Threads=1、Hash=16 MiB、MultiPV=1、定跡なし、全合法手生成。コマンドは `go depth 2 nodes 400000 movetime 3000`。通常の静止探索予算2、非終端の絶対ply8での中断も維持した。

`Phase0MoveOrder` に `main` と `q` を追加した。`lexical` は辞書順、`main` は主探索だけ駒取り・成り優先、`q` は静止探索だけ優先、`tactical` は両方。非王手の静止探索では候補がもともと駒取り・成りのみなので、`q` による順序変更が起こるのは静かな回避手も含む王手時である。同一の優先区分内は辞書順とし、候補・葉の条件・探索窓・深さを変えていない。

各局面で、全幅参照1設定、新バイナリのαβ4設定、旧Phase 0dの辞書順／両方優先2設定を比較した。旧版との10組では評価・手・PV・ノード・完了深さ・停止理由が一致した。

記録は各探索直後に保存し、1回のコマンドで新たに扱うのは1局面まで。プロセスは同時に1つ、外部応答待ちは8秒。静止探索の安全上限に達した場合、そのSFEN・経路・残り予算・王手状態を保存する観測機能を追加した。

### 中盤の悪化はどこで生じたか

後手中盤では主探索だけの並べ替えで56.2%増、王手回避だけでは1.0%減だった。今回の切替実験では、悪化は主探索側にある。

選択手 `1f1h` は駒取り・成りではなく、根の順序は辞書順4番目から優先順10番目へ後退した。よい静かな手の確認が遅れることが悪化要因の候補になる。ただし、主探索内の全ノードを並べ替えているため、根の順位変化だけに増加分を帰属することはできない。

終盤先手の選択手 `P*7i` も静かな手だが、根の順位は45番目のままで、主探索だけの並べ替えでも56.4%減った。このため「静かな最善手なら駒取り優先が悪い」という単純な説明でも不十分である。相手応手や内部ノードの順序・境界更新を観測する必要がある。

### 主探索と王手回避の効果は加算できない

前回の先手中盤では、主探索だけで871ノード、王手回避だけで169ノード減った。足すと1,040だが、同時適用の削減は931だった。先手終盤でも単独削減の合計は8,278、同時適用は6,880で一致しない。探索窓と訪問先が変わるため、個別効果には重複・相互作用がある。

王手回避だけの優先順は今回の5件すべてでノードを減らしたが、削減率は0.08〜18.6%と幅がある。5件の観測だけで一般に有効と確定せず、学習済み方式の効果とも扱わない。

## 5. 終盤で見つかった過剰な中断の候補

後手176手目の全幅探索は次の8手で中断した。

```text
G*4e 6g6f 5e4f 2c4e 7b4e G*5f 4e5f 7h6i
```

経路を別の合法手実装で再生し、停止局面の盤面・手番・持駒・王手状態が一致した。到達時は **王手ではなく、静止探索の残り予算は−4** だった。現在はply8の検査が通常の葉判定より前にあるため、本来の「非王手・予算消費済みなら静的評価を返す」条件を満たしていても反復を中断する。

今回の4方式比較では条件を固定するため、この規則を変えていない。次は王手が残る場合の中断を保ちつつ、通常の葉条件を満たす場合だけ評価を返す変更を、保存したこの経路から小規模に検証する。ノード・時間・到達plyの上限を増やす必要はない。

## 6. 時間・復元・監査

時間は今回も監査・観測込みの単回値。例えば両方優先の探索時間は先手中盤24.1 ms、後手中盤56.6 ms、先手終盤38.5 ms、後手終盤32.7 ms、過去失敗局面23.0 msだった。主探索のみの先手中盤はノードが減ったにもかかわらず42.96 msとなり、辞書順25.72 msより遅い単回観測もある。安定した速度比較には測定の反復と監査無効の別実験が必要で、ここでは時間短縮率を主張しない。

- 比較35探索（全幅5、新αβ20、旧αβ10）、選択手確認4探索、強制中断・再開10探索、合計49探索。
- NNUE差分計算と全再計算の照合1,843,754回、不一致0。照合回数は重複局面を含む呼出回数。
- すべての探索で根の盤面・StateInfo・キー・評価の復元を確認。PVと代替手は合法。
- 各局面の2ノードでの中断後、position再設定なしの再探索が基準の評価・手・PV・ノード・停止理由に一致。
- 時間上限による中断はなし。全幅でノード上限3件、安全ply上限1件を実際に通過。

## 7. 判断と次の一歩

1. 主探索の駒取り・成り優先は改善と悪化の両方を示した。一律に標準採用しない。
2. 静かな有力手を後回しにしない候補として、前の反復のPV優先や履歴を、別の単一変更として検証する。今回の5局面は開発用に固定し、新しい評価用局面と混ぜない。
3. まず終盤で見つかった「通常の葉でも安全上限により中断する」経路を修正・確認する。その後、悪化した後手中盤で境界更新・候補別費用を追い、遅くなった場所を特定する。

深い教師による着手品質・対局・勝率は今回未測定。難しい中終盤に対する実用棋力が十分とはまだ言えない。
