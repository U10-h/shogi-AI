# 通常cpと特殊値の区別（結果取得後の集計修正）

根3の教師は P*8f を -31111cp と出力した。固定上流ソース types.h の VALUE_SUPERIOR=28000 raw、PawnValue=90による変換と一致し、通常NNUE評価の最大値27000raw（30000cp）を超える。全方式が同じ手を選んだ局面で、全方式の生平均へ同じ大きな差を加える。

元の384探索と教師応答は変更しない。`raw_cp_gap` と `raw_all_cp_mean_gap` に当初の全16根の集計を残す。主たるcp集計は、候補のうち通常cp以外、または絶対値30000cp超を含む根を除外する。この規則で15根を集計し、除外根3を明示する。特殊値は勝率や普通の形勢点に換算しない。これは新規結果を見た後の出力形式修正で、当初から事前登録した規則とは扱わない。
