# v1.0 Phase 0c — 共通NNUE上の限定静止探索

2026-09-27。Phase 0bと同じ2局面で、限定静止探索を最小探索へ接続した。主探索深さ2・静止探索の通常予算2に限定し、比較12探索と中断・復元確認10探索を完了した。静止探索付きの全幅探索とαβ探索は、両局面で評価値・最善手・PVが一致した。棋力向上を示す実験ではない。

## 今回追加した処理

`native/phase0c_search.cpp` を別バイナリに組み込み、Phase 0bの実装と結果を保存したまま比較した。盤面、合法手生成、NNUE重み、`Eval::evaluate`、`do_move`によるノード計数は固定上流YaneuraOu 6.03/KP256と共通。

既存 `src/advanced.cpp` の静止探索から、非王手時のstand-pat（その場の静的評価）、駒取り・全ての成り、王手時の全合法回避手という基本方針を移した。手の並びはUSI表記の辞書順。既存の高速化、置換表、履歴、SEE/delta枝刈り、LMR、学習した読み順はまだ移していない。

- 非王手では残り予算0で静的評価を返す。それより前はstand-patと駒取り・成りを比較する。
- 王手ではstand-patを使わず、残り予算が0以下でも、駒打ちや静かな手を含む全回避手を読む。
- 終端・反復判定後、根からの絶対plyが8に達した場合は、その反復を未完了として中断する。未解決の王手を静的評価で確定させない。
- 40万ノード・3秒の内部上限も設けた。中断時は着手を巻き戻し、直前に完了した反復だけを採用する。初回反復も未完了なら合法手の代替を返す。

`minimax` は主探索と静止探索のαβ枝刈りを無効にし、同じ葉の規則を使う参照実装。全幅とは、この限定した探索木を省略なく読む意味であり、無制限の完全探索ではない。

## 条件と結果

入力は `experiments/phase0b-positions.json` の初期局面と角交換後の局面を固定。各方式を直列に実行し、1コマンドにつき新規1局面だけを処理した。Threads=1、Hash=16 MiB、MultiPV=1、定跡なし、全合法手生成、`go depth 2 nodes 400000 movetime 3000`。比較探索はNNUE監査を有効にした。

| 局面 | 静止探索なしαβ：手 / ノード | 静止探索あり全幅：手 / ノード | 静止探索ありαβ：手 / ノード | あり全幅とαβのraw評価 |
|---|---|---|---|---:|
| 初期局面 | `2g2f` / 181 | `2g2f` / 1,364 | `2g2f` / 195 | 92 |
| 角交換後 | `7i8h` / 2,396 | `3i4h` / 72,437 | `3i4h` / 1,691 | 29 |

両局面とも主探索深さ2を完了し、比較中に上限で中断した探索はなかった。PVも全幅とαβで一致した（初期局面 `2g2f 3c3d`、角交換後 `3i4h 2b3c`）。評価値は上流のraw単位であり、通常のUSI cpとは異なる。

角交換後では静止探索を加えると選択手が変わり、同じ深さ2の標準YaneuraOuと一致した。標準との着手一致は1/2から2/2になったが、深い独立教師での品質検証ではなく、少数の既知局面の観察にとどまる。静止探索なしのraw評価−121から29への変化も、読む範囲が変わった結果であり、棋力改善量とは解釈しない。

ノード数は初期局面で181→195、角交換後で2,396→1,691となった。静止探索により評価の境界が変わり、その後のαβの打切り方も変わるため、ノード数は増える場合と減る場合がある。同一の葉を保つ高速化とは区別する。全幅からαβへの削減も通常のαβ枝刈りの効果であり、新規学習による効果ではない。

## 動作確認

| 確認 | 結果 |
|---|---|
| 旧Phase 0b標準探索と新バイナリの標準探索 | 両局面で評価・手・PV・ノード・完了深さが一致 |
| 旧Phase 0bの静止探索なしαβと新バイナリの同設定 | 両局面で評価・手・PV・ノード・完了深さが一致 |
| 静止探索あり全幅とαβ | 両局面で評価・手・PV・完了深さが一致 |
| NNUE差分計算と全再計算 | 静止探索付き比較4探索で75,031照合、不一致0 |
| 通常予算を使い切った後の王手回避 | 4探索合計4,716訪問。角交換後αβだけでも56訪問 |
| PVの合法性 | 保存した全探索で確認 |
| 2ノード上限による静止探索中断 | 両局面で中断・根の復元を確認 |
| `go infinite`中の外部`stop` | 両局面で中断・根の復元を確認 |
| 中断直後、position再設定なしの再探索 | 両中断方式・両局面で基準の評価・手・PV・ノードに一致 |
| NNUE監査を無効にした再探索 | 両局面で同じ評価・手・PV・ノード |

根の復元は実際に探索したPositionのSFEN、キー、StateInfoポインタ、差分評価、全再計算評価で確認した。最大到達plyは初期局面4、角交換後5。通常予算「主探索2＋静止探索2」を超えた王手回避も実際に通過した。駒取り数と成り数は重複する場合がある。

時間の単回観測は、初期局面の静止探索なし/ありαβが1.91/1.92 ms、角交換後が15.50/13.86 ms。監査を含む1回ずつの値なので速度改善の根拠にはしない。

## 制限と次の一歩

既知の2局面、古い固定6.03/KP256、浅い探索の接続試験である。終盤・反復局面・長い連続王手を広く検証していない。絶対ply8の中断経路は今回発動していない。既存v0.x探索全体の移植、学習、対局、棋力測定は未実施。

次は同じ2局面・主探索深さ2・静止探索予算2を維持し、まず駒取り・成りを優先する読み順だけを追加する。読み順が変わると同点の手やPVが変わり得るため、全幅の評価値一致を必須とし、手が変わる場合は同点かどうかを確認する。1局面ずつ保存し、置換表や学習は同時に追加しない。
